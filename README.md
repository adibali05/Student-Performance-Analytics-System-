# Student Performance Analytics System

A Python-based data analysis project that reads, processes, and analyzes student performance data. Built using Pandas and NumPy.

## Features
* Automatically generates a sample dataset of 20 students.
* Calculates total marks, average scores, and assigns grades.
* Determines Pass/Fail status based on strict criteria (minimum 40 marks per subject, minimum 75% attendance).
* Analyzes overall class performance and subject-wise metrics.
* Identifies top-performing students.

## Technologies Used
* Python
* Pandas
* NumPy

## How to Run
1. Ensure Python is installed on your system.
2. Install the required libraries: `pip install pandas numpy`
3. Run the script: `python Student-Data/main.py`
